## Context
MCP-capable agents of any vendor must use the same logic as the CLI.

## Decision
Register one MCP tool per core operation returning JSON text content.

## Why
A thin one-to-one mapping keeps behavior identical across interfaces and easy to extend.

## Consequences
Tool schemas must track core signature changes.
