## Context
The core goals are never losing context while optimizing token use.

## Decision
Assemble active task + semantically ranked decisions/learnings + a memory tail, greedily filling a token budget.

## Why
Selective, ranked retrieval beats dumping history: it preserves continuity while keeping prompts small.

## Consequences
The ~4 chars/token estimate is approximate; budgets are soft.
