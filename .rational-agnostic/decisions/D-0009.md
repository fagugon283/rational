## Context
We must answer 'why does this function exist' from code.

## Decision
Maintain an index from decision id to the code anchors that cite it, each with a body SHA.

## Why
A central map enables reverse lookup by file+symbol or by hash, and powers drift detection.

## Consequences
The registry must be kept in sync via tag_code; verify flags stale anchors.
