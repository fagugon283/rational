## Context
Semantic search must work everywhere, even offline or without the optional model.

## Decision
Define an Embedder interface; use the local model if its optional dependency loads, else a hashing bag-of-words embedder.

## Why
Graceful degradation keeps search functional on any machine while allowing real semantic quality when the model is present.

## Consequences
Lexical fallback is lower quality; results differ by provider, so the index records which embedder built it.
