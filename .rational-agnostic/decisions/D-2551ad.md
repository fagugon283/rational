## Context
Running init --force to regenerate AGENTS.md also overwrote memory/shared.md, knowledge/learnings.md and conventions.md, destroying accumulated agent data.

## Decision
Seed data-store files only when missing, ignoring --force; restrict --force overwrites to AGENTS.md and config.json.

## Why
Data stores accumulate irreplaceable multi-agent history; a scaffolding flag must never delete user/agent data.

## Consequences
To intentionally reset a data store, delete the file manually; --force no longer touches them.
