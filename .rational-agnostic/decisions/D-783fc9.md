## Context
Users install via npx but each AI agent (Claude Code, Cursor, Codex, Gemini, Copilot) discovers MCP servers and reads instruction files from different, client-specific paths. AGENTS.md alone cannot self-register an MCP server. The goal is that 'npx rational-agnostic init' leaves every supported agent wired with no manual config.

## Decision
init writes/merges per-agent MCP configs (.mcp.json, .cursor/mcp.json, .vscode/mcp.json, .gemini/settings.json, .codex/config.toml) and instruction pointer files (CLAUDE.md, GEMINI.md, .github/copilot-instructions.md) that reference AGENTS.md. All writes are non-destructive merges that preserve existing user servers/content. Disabled with --no-mcp.

## Why
Each agent looks at a different filename/path for both MCP registration and project instructions; generating the right-named file for each is the only way to achieve true zero-config across vendors without touching the user home dir.
