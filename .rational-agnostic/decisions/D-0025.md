## Context
Source files (tests, fixtures, the scanner itself) legitimately contain @why: strings as data or examples, which the traceability scan would flag as orphan tags.

## Decision
Read a gitignore-style .rationalignore at the repo root and skip matching files during scanning.

## Why
Every code scanner needs an escape hatch; a familiar gitignore-style file keeps authors in control without weakening enforcement for real code.

## Consequences
Tags inside ignored paths are not checked; patterns are the user_s responsibility.
