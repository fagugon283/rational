## Context
Several agents may write the same store simultaneously.

## Decision
Wrap writes in a named lock (proper-lockfile) with retry/backoff and a stale timeout.

## Why
File locks are simple, dependency-light and work across processes without a daemon, fitting the file-based design.

## Consequences
Lock contention adds latency under heavy parallelism; bounded by retries.
