## Context
The tool must be vendor-agnostic and work without API keys.

## Decision
Default embeddings.provider=local (Xenova/all-MiniLM-L6-v2); provider is swappable in config.

## Why
Local embeddings keep the tool offline, free and private by default, true to the 'agnostic' name; config allows upgrading to an API provider.

## Consequences
First run downloads ~23MB model; mitigated by caching and a lexical fallback.
