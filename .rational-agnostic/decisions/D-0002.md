## Context
Commands can run from any subdirectory of a repo.

## Decision
Walk parent directories until a .rational-agnostic folder is found; that parent is the repo root.

## Why
Mirrors how git finds .git, so the tool works from anywhere in the tree without configuration.

## Consequences
A stray .rational-agnostic in a parent dir could capture a nested repo; acceptable and git-like.
