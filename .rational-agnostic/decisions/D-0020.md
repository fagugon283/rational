## Context
The user required that AGENTS.md not reveal what the host project is about.

## Decision
Ship a generic AGENTS.md template describing structure, protocol and connection only.

## Why
Keeps the manifest portable and privacy-preserving; project rationale lives in decisions instead.

## Consequences
Teams wanting a project overview must add it elsewhere (e.g. overview.md).
