## Context
Users want to add rational-agnostic to an existing project and have a chosen AI agent explore it and initialize everything. The deterministic tool cannot know why legacy code exists.

## Decision
Split the work: a deterministic adopt command/tool inventories the repo (languages, manifests, entry points, largest files, tag coverage) and emits a plan + onboarding prompt; the user_s agent does the understanding via MCP, backfilling decisions and tags. start_adoption records an honest as-built baseline, a task and a shared-memory brief.

## Why
Only the LLM can infer design intent; the tool must not fabricate rationale. Inventory + plan give the agent a fast, deterministic starting point while keeping integrity.

## Consequences
Legacy code stays untagged until revisited; adoption is incremental and non-destructive.
