## Context
Agents of different vendors need a common, durable workspace.

## Decision
Provide a shared memory file plus optional per-agent scratch files, with attributed append.

## Why
Shared memory is where one vendor's agent reads what another left behind, enabling collaboration without a server.

## Consequences
No automatic conflict resolution beyond locking and append.
