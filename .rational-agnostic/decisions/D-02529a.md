## Context
User wants an npm/Node package to work with any modern editor; competitor scan showed AGENTS.md is an open standard and memory/traceability tools exist but are framework-bound.

## Decision
Publish as a public, MIT-licensed npm package with MCP server + CLI + library entry points; name confirmed free on npm.

## Why
An open, vendor-neutral package fits the AGENTS.md ecosystem and maximizes cross-tool adoption; MIT lowers friction.

## Consequences
Requires stable semver and public API discipline; user currently has no npm account so publish is deferred.
